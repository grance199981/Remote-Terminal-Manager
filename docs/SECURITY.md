# 安全说明

Remote Terminal Manager MVP 的安全边界：

## 允许用途

- 管理自己的服务器、NAS、实验机或开发机；
- 连接已获得明确授权的 SSH 主机；
- 在本机打开 PowerShell / CMD；
- 保存非敏感设备配置，例如主机、端口、用户名、私钥路径。

## 不允许用途

- 未授权连接第三方设备；
- 隐蔽安装或后台控制；
- 绕过向日葵、ToDesk 或其他商业软件的付费/VIP限制；
- 收集、转发或外泄密码、私钥、会话内容；
- 制作木马、后门、持久化控制端。

## 凭据处理

- SSH 密码只在连接时输入，不写入 `devices.json`；
- 私钥登录只保存私钥文件路径；
- 当前 MVP 没有实现主密码和本地加密库，后续版本建议增加系统钥匙串集成。

## 后续增强建议

- 使用 Windows Credential Manager / macOS Keychain / libsecret 保存敏感凭据；
- 增加主密码；
- 增加已知主机指纹校验；
- 增加操作日志；
- 增加设备配对码和远程 Agent 授权确认。
